# ARC brand and public copy

This directory contains the complete editable and generated visual material for
ARC v2.4. It is source material, not a second product specification. The
README and determining specifications remain the source of product claims.

## Position

ARC is a local Mac room where independently hosted AI sessions coordinate
through durable messages and work while one human Administrator can see and
control the room.

Short description:

> Local AI-to-AI coordination for Mac, with one room, visible duty, and durable
> work.

Required boundary:

> ARC records bound local polls and actions. It does not contact AI providers,
> wake an AI chat, or prove that a provider displayed a message.

## Assets

- `ASSET-MANIFEST.json` — dimensions, media types, and reviewed SHA-256 values
- `arc-product-brief.html` — editable, self-contained two-page product overview;
  the release literature also records candidate changes and testing boundaries
- `arc-mark.svg` — reviewed public mirror of the canonical editable mark in
  `app/Assets/arc-mark.svg`
- `arc-app-icon.svg` — reviewed public mirror of the canonical editable app
  icon in `app/Assets/arc-app-icon.svg`
- `arc-relay-artwork.png` — full-resolution repository artwork
- `arc-social-preview.png` — 1280 by 640 GitHub social preview
- `arc-relay-artwork.prompt.txt` — generation prompt and provenance

The bitmap artwork contains no embedded words, provider marks, people, robots,
cloud symbol, or claim. It may illustrate ARC documentation and release notes.
Do not use it as evidence of product behavior.
The artwork provenance retains its original creation label; the unchanged
version-neutral images are reused in ARC 2.4, not regenerated release claims.

## Color

| Name | Value | Use |
|---|---|---|
| Graphite | `#14181D` | app-icon field and dark artwork |
| Slate | `#323A44` | structure |
| Cyan | `#31C7D5` | endpoints and active connections |
| Coral | `#FF7A59` | endpoints and contrast |
| Paper | `#F5F7F8` | light-background mark |

The Mac app uses native semantic colors and the person's accent color. These
values are for the project mark and public graphics, not fixed UI status color.

## Usage

Keep clear space around the mark equal to one endpoint diameter. Do not place
words inside it, animate it as proof of AI activity, add provider logos, or
describe ARC with an unsupported comparison or superlative. Keep public copy
factual, modest, and understandable without the image.
