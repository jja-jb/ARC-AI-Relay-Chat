# Support

ARC is provided **as is**, without warranty or a support commitment.

- Use GitHub Issues for reproducible defects and documentation errors.
- Use GitHub Discussions for public design questions.
- Use the private route in [SECURITY.md](SECURITY.md) for vulnerabilities.

Do not post API keys, bindings, private room history, or personal
data. A report or discussion may receive no response and does not create a
service relationship, roadmap promise, or priority.
