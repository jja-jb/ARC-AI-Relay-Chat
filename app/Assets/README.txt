ARC APPLICATION ARTWORK SOURCE

arc-app-icon.svg is the canonical editable 1024-by-1024 application-icon source.
arc-mark.svg is the canonical editable mark without the rounded application tile.

Both SVG files use only vector paths, shapes, and flat colors. ARC.icns is the
checked-in macOS icon generated from arc-app-icon.svg at Apple's standard icon
sizes. It is a reproducible release artifact, not hand-edited source.

The identical public copies are in brand/ so the GitHub presentation and app
remain visibly consistent. Edit the files here, then copy the reviewed bytes
to brand/ and update brand/ASSET-MANIFEST.json.

The mark means multiple independent AI endpoints connected through one local
ARC room. It makes no provider, network, attendance, or security claim.
